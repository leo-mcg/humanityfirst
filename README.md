# Humanity First Canada — donor-first site (first pass)

Static one-page site for [Humanity First Canada](https://www.humanityfirstcanada.ca/), built free by Good Pages Studio. Live: https://leo-mcg.github.io/humanityfirst/

- Plain HTML/CSS, no build step, no JavaScript. Hosted on GitHub Pages from `main` (root). `.nojekyll` included.
- All copy, figures and photos come from humanityfirstcanada.ca (photos from its image CDN, resized and stored in `assets/img/`).
- Donations are not processed here: every Donate button links to the existing flow at https://www.humanityfirstcanada.ca/donate-now, or to a campaign-specific donate URL from their site (Gift of Sight → cataract surgeries, Masroor Centre for Healthcare).

## Open questions
